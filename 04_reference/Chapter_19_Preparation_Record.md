## 3. Contract Lock

### 3.1 Governing question

> What exactly changes when a source object is reconstructed at finer resolution?

Chapter 19 must answer this at the coordinate and relation level. It must not answer the Chapter-20 question of which components and relations actually constitute the finer reconstruction.

### 3.2 Required core claim

```text
Granularity change alters the distinction set and resolution
while preserving a declared relation to the same source reference.
It is not a descent toward deeper truth.
```

The claim has five conjunctive burdens:

1. source and target granularities are explicit;
2. the distinction-set change is stated rather than implied by added volume;
3. the source reference remains declared or its change is acknowledged;
4. Frame preservation or change is separately marked;
5. the expected praxeological difference is stated before operation execution.

### 3.3 Frame rule

A Frame change may accompany a later decomposition, but:

```text
Frame change
≠ granularity change
≠ DECOMPOSE
```

The analysis must distinguish:

- finer reconstruction within the same Frame;
- movement into an internal subframe while retaining source lineage;
- movement to a different analytical Frame and new claim;
- movement to a target context that may later require `PROJECT_AS`.

### 3.4 Component rule

A relevant component is not merely a smaller piece. It must be tied to the source object by a source-supported relation and must carry, modify, disturb, constrain, or test the coarser reconstruction.

```text
fragment
≠ source-relevant component
```

The component criterion is relational and claim-bound, not spatial, ontological, or automatically causal.

### 3.5 Required distinctions

Chapter 19 must keep distinct:

```text
granularity ≠ Frame
finer resolution ≠ deeper truth
relative downward movement ≠ ontological lower layer
functional component ≠ fragment
local part ≠ spatially contained part
local structure ≠ distributed structure
```

### 3.6 Completion criteria

Chapter 19 can be provisionally locked only if:

## 5. Chapter-19 Object: The Granularity Relation

The Chapter-19 object is not the source object alone and not the later finer reconstruction alone. It is the declared relation between two analytical resolutions of a bounded reference object.

A minimal conceptual form is:

```text
source reference
+ source granularity
+ target granularity
+ distinction-set change
+ Frame status
+ reference status
+ expected praxis difference
+ comparability status
→ granularity relation prepared for Chapter 20
```

The relation remains a claim. Its declaration does not prove that the target granularity is empirically supportable, useful, or admissible.

### 5.1 Relation identity

The relation should state:

- along which dimension the target is finer;
- which source distinctions are divided, enriched, temporally segmented, or relationally traced;
- which distinctions remain stable;
- which source relation is meant to remain reconstructible;
- what comparison would count as success, neutrality, or failure later.

The words “micro,” “meso,” “macro,” “deeper,” “inside,” or “below” are insufficient without a comparator and relation.

### 5.2 Multi-dimensional granularity

Granularity is not assumed to be one scalar. A reconstruction may be finer with respect to temporal segmentation and coarser with respect to institutional scope. Chapter 19 therefore requires a declared comparison dimension rather than a universal ranking.

```text
finer along dimension A
≠ finer along every dimension
```

Where no coherent single relation can be stated, the analysis must preserve several local relations or remain underdetermined. It must not force one global hierarchy.

## 6. Granularity Change

Granularity change means a changed distinction set used to reconstruct and test the source reference. It is not measured by word count, number of observations, data volume, code length, or rhetorical detail.

A valid preparation must answer:

1. Which distinction was previously compressed?
2. Which target distinction is proposed?
3. Why does that distinction matter to the bounded claim?
4. Which source route could support it?
5. What would count as no praxeological gain?
6. What wider relation might become less visible at the finer resolution?

### 6.1 Source-to-target direction

The usual SUB direction is:

```text
coarser source representation
→ finer target representation
```

But “finer” must be declared relationally. Examples include:

- episode units → transition and repair units;
- one Non-Event window → successive delays, blocks, and repeated non-decisions;
- one Path segment → source-supported subpaths and transitions;
- one distributed Asymmetry claim → role-, access-, cost-, and timing-relations;
- one Frame-typed occurrence → source-supported reproduction practices.

These examples identify candidate relation forms only. They do not discover the target components.

### 6.2 No truth descent

Chapter 19 must explicitly reject:

```text
finer granularity
→ deeper reality
→ higher truth
→ higher authority
```

A finer reconstruction may be more discriminating for one claim and less useful for another. It may expose a coarse error, preserve the coarse result, fragment the source relation, exceed sources, or remain incomparable to another analysis.

## 7. Relative Downward Movement

“Downward” is a relation between declared analytical positions. It is not a claim that reality contains fixed lower strata.

A relative downward movement may mean:

- a composite is opened toward constitutive or disturbing relations;
- an occurrence is opened toward its reproduction conditions;
- a Path is opened toward transitions and subpaths;
- a Trajectory is opened toward segments, carriers, and sedimentation routes;
- a structured Non-Event is opened toward expectation windows, delays, blocks, and repeated non-realizations.

The movement does not by itself establish:

- a universal micro-level;
- smaller spatial objects;
- more fundamental causes;
- final constituents;
- a lower operator rank;
- a new PMS primitive.

### 7.1 Comparator burden

Every relative-level statement requires:

```text
object
+ comparator
+ relation
+ purpose
```

“Lower” without those four elements is non-operational shorthand.

### 7.2 Relative level versus granularity

A finer granularity can occur without a changed relative level. The same conversation may remain the composite relative to the same utterance-and-response family while the analysis distinguishes repairs more finely.

A changed relative level can occur without finer granularity. The same conversation may be positioned as one constituent of a quarterly process while retaining its decision-sequence resolution.

```text
finer granularity
≠ lower relative level automatically
```

## 10. Change of Distinction Set

The target granularity must specify what differences become analytically visible. Candidate distinction families include:

- role-position and response-capacity differences;
- local cost, exposure, and access differences;
- event, sub-event, and transition differences;
- expectation, delay, blockage, and non-realization differences;
- repetition and reproduction conditions;
- temporal windows and thresholds;
- parallel or competing subpaths;
- local versus distributed carrier relations.

The preparation must not treat this list as a closed ontology or as evidence that every candidate distinction exists in the source.

### 10.1 Added distinction versus added description

A changed distinction set must alter how the reference is partitioned or related. Synonyms, additional quotations, more adjectives, or repeated examples do not establish a new granularity.

### 10.2 Claim relation

Each proposed distinction must state which warranted reconstruction it could change. A distinction with no possible claim relation is below the chapter's preparatory relevance burden.

## 11. Local versus Distributed Structure

Chapter 19 must prevent spatial atomism. A source-relevant component may be:

- locally concentrated;
- temporally distributed;
- distributed across roles;
- institutionally distributed;
- distributed across documents and procedural sites;
- relationally constituted between positions;
- recurrent across non-contiguous occurrences.

A distributed component is not automatically a macro-object. It is a finer reconstruction of how the same source object is carried across locations, times, roles, or relations.

### 11.1 Temporal distribution

One apparently punctual Non-Event may be carried by repeated delay, handoff failure, blocked responsibility, and missed windows. The component relation is temporal; no single moment contains the whole structure.

### 11.2 Role distribution

One coarse Asymmetry claim may be carried by unequal access, response capacity, documentation authority, exposure, and exit cost across several role-positions. No individual role difference alone proves the coarse claim.

### 11.3 Institutional distribution

A Frame-typed occurrence may be reproduced by agenda admission, access rules, role assignment, recordkeeping, and closure procedures located in different institutional sites.

The preparation identifies these as possible distribution forms only. Chapter 20 must reconstruct actual components and relations from sources.

## 12. Functional Components versus Mere Fragments

The canonical component test is conjunctive. A proposed component must have:

1. a declared relation to the source reference;
2. source support or an explicitly bounded source route;
3. a carrying, modifying, disturbing, constraining, or testing relation to the coarser function or claim;
4. praxeological relevance to the current reconstruction;
5. a relation to other proposed components rather than isolated detail status.

A fragment may be accurate, detailed, and interesting while failing this test.

### 12.1 Carrying component

A carrying component contributes to the reproduction or constitution of the source function. It is not automatically necessary or sufficient on its own.

### 12.2 Disturbing component

A disturbing component reveals internal heterogeneity, contradiction, interruption, or counterevidence that may weaken or reject the coarser function. Source relevance therefore does not mean source-function preservation.

### 12.3 Replaceable component

A component may be replaceable while the coarser function persists. Chapter 19 must not infer necessity from participation. Chapter 20 and later Counterfactual Component Tests own that burden.

### 12.4 Fragment failure

A proposed fragment fails the preparatory component test when it:

- has no traceable relation to the source object;
- is selected only because it is small or vivid;
- cannot affect the bounded reconstruction;
- is unsupported by the source basis;
- is disconnected from other internal relations;
- or changes the topic rather than the granularity.

```text
detailed fragment
≠ component
≠ constitutive component
≠ causal component
```

## 13. Granularity Comparability

Two finer reconstructions of the same source object are comparable only under a declared basis. The Chapter Contract requires at least:

- same source reference or explicitly related references;
- compatible or translatable Frames for the tested predicate;
- sufficiently aligned temporal scopes;
- comparable source standards;
- declared source and target granularities;
- a traceable relation between the target distinction sets;
- disclosed losses and exclusions.

### 13.1 Comparable

The reconstructions answer the same bounded question under aligned coordinates and can be translated or traced without erasing constitutive structure.

### 13.2 Comparable with declared translation

The reconstructions use different but translatable distinction sets. The translation rule and its losses must be explicit.

### 13.3 Partially comparable

Some predicates or segments align while others do not. Claims must be segmented; partial comparability cannot be generalized to the whole object.

### 13.4 Incomparable or underdetermined

The Frames, temporal scopes, source standards, predicates, or target distinction dimensions do not support a responsible comparison. Incomparability is a positive bounded finding, not a proof that both claims are true.

These labels are local comparison descriptions, not new canonical Output Classes and not a new closed model enum at the Preparation Gate.

## 14. Granularity Mismatch versus Substantive Contradiction

A granularity mismatch occurs when two reconstructions use non-aligned distinction sets and appear to disagree. The first task is to determine whether they answer the same question.

Prepared comparison:

- coarse claim: the review conversation reached documented procedural closure;
- fine claim: several repair attempts remained interactionally unresolved before closure.

These claims may coexist because procedural closure and complete interactional resolution are different predicates.

Prepared substantive contradiction:

- claim A: the identified role-position possessed and exercised final decision authority in the bounded conversation;
- claim B: the same source contains no supported authorization or exercise by that role-position.

Different granularities do not make both claims true when Frame, reference, temporal scope, and predicate align.

```text
different granularity
≠ different predicate automatically
≠ contradiction automatically
≠ contradiction dissolved automatically
```

### 14.1 Invalid neutralization

The statement “both are correct because one is micro and one is macro” is invalid unless the predicates, Frames, and relation can be shown to permit coexistence.

### 14.2 Claim reduction

Where the fine reconstruction supports only a narrower claim, the coarse claim may later require `claim_reduction_required`. Chapter 19 identifies the comparison pressure; Chapter 20 and Chapter 25 own operation and outcome classification.

### 14.3 Non-Capture boundary

A forced universal scale classification may remain uncaptured. `non_capture` may not protect an unsupported local claim or turn unresolved contradiction into plural validity.

## 15. The Lower Granularity Question

The central Chapter-19 test is:

> Does the additional distinction change a warranted reconstruction of the praxis-relevant structure?

The question is asked before resolution outcome selection. It has four possible preparatory states:

- a plausible source-supported difference is identified;
- the expected difference is present but source support remains open;
- no claim-relevant difference can be stated;
- the question cannot be responsibly answered under current sources or coordinates.

### 15.1 No automatic gain

A valid finer description may leave the warranted reconstruction unchanged. It may also reduce calibration, hide wider relations, or create fragmentation.

### 15.2 No premature result class

Chapter 19 may prepare pressure toward:

- resolution gain;
- `resolution_neutral`;
- resolution drift;
- resolution escape;
- source overreach;
- calibration loss;
- Stop;
- Non-Capture.

It may not assign those outcomes. Chapter 25 owns their full classification after a valid `DECOMPOSE` occurrence or bounded no-continuation finding.

### 15.3 Non-compensation

More details cannot compensate for:

- missing PraxisPurchase;
- missing source support;
- broken reference continuity;
- Frame confusion;
- incompatible temporal scope;
- failed Type Integrity;
- or authority overreach.

## 16. Minimal Granularity Relation

The Chapter-19 conceptual declaration is:

```yaml
granularity_change:
source_granularity:
target_granularity:
distinction_added:
frame_preserved:
reference_preserved:
expected_praxeological_difference:
comparability_status:
```

### 16.1 Field meaning

- `granularity_change`: bounded description of how the distinction set changes;
- `source_granularity`: Chapter-18 source resolution;
- `target_granularity`: proposed finer resolution, not yet substantively confirmed;
- `distinction_added`: the new difference or relation to be tested;
- `frame_preserved`: whether the same analytical Frame remains operative; if false, the new Frame and claim must be separately declared elsewhere in the record;
- `reference_preserved`: whether the same source reference remains reconstructible;
- `expected_praxeological_difference`: what warranted reconstruction could change;
- `comparability_status`: local comparison declaration with rationale and uncertainty.

### 16.2 Not a parallel schema

The Minimal Granularity Relation is a readable conceptual form, not a second machine schema. It maps to existing locations:

| Conceptual field | Existing record location or controlled carrier |
| --- | --- |
| source granularity | `/source/granularity` |
| target granularity | `/target/granularity` |
| source Frame | `/source/frame` |
| target Frame | `/target/frame` |
| source reference | `/source/reference_object` |
| target reference | `/target/reference_object` |
| expected difference | `/operation/expected_praxeological_difference` |
| granularity-change rationale | operation justification, relation declarations, or controlled `extensions` payload |
| distinction added | controlled `extensions` payload or later operation-specific declaration |
| comparability status | controlled `extensions` payload and claim/relation rationale until a later owner justifies schema change |

No schema change is required at the Preparation Gate. A record-local extension must declare owner/source, control pointer, purpose, payload, and that it does not replace required fields.

### 16.3 Boolean caution

`frame_preserved` and `reference_preserved` are not inferred from matching labels. They are claims requiring rationale. A false value does not automatically fail every transformation, but it may create a new claim, operation boundary, or Mandatory Stop depending on what changed.

## 17. Source Support, Loss, and Claim Ceiling

### 17.1 Source support

The target distinction set must be supportable by the source basis. Candidate units cannot be populated from the coarse label alone.

Required source declarations include:

- direct source traces;
- indirect reconstruction routes;
- unresolved intermediate structure;
- source version and access limits;
- competing finer models;
- unavailable or irrecoverable distinctions.

### 17.2 Loss in both directions

The granularity relation must anticipate loss:

```yaml
loss:
  preserved:
  compressed:
  excluded:
  uncertain:
  irrecoverable:
```

A finer reconstruction may preserve local sequence while losing wider procedural visibility. A coarser reconstruction may preserve the overall function while compressing internal heterogeneity. Neither direction is lossless.

### 17.3 Claim ceiling

The target claim may not exceed:

- the supported target distinctions;
- the retained source reference;
- the declared Frame;
- the temporal and source scope;
- the comparability basis;
- the current operation stage.

Chapter 19 cannot raise the claim ceiling merely by declaring a more detailed target granularity.

## 18. Stop and Non-Capture

### 18.1 Optional Stop

Optional Stop is appropriate where:

- the coarse representation already carries the current claim;
- the proposed distinction has no additional praxeological purchase;
- finer analysis would reduce calibration or comparability;
- the target relation is unnecessary for the current work package.

### 18.2 Mandatory Stop

Mandatory Stop is required where:

- the source and target reference cannot be related without substitution;
- a Frame change is concealed as finer granularity;
- the target distinction set is unsupported;
- an operator type is treated as a decomposable aggregate;
- “lower level” is used as ontological or authority language;
- the proposed component relation is only a fragment list;
- incomparability is used to protect a failed claim;
- the source ceiling is exceeded.

### 18.3 Non-Capture

Non-Capture remains available where:

- several source-supported target partitions cannot be reduced to one responsible granularity relation;
- the object is distributed across incompatible but locally valid relations;
- a forced universal micro–meso–macro classification would erase relevant structure;
- available sources cannot choose among materially different finer models.

Non-Capture does not:

- validate every rival model;
- preserve an unsupported coarse claim;
- establish that no future decomposition is possible;
- create a new primitive;
- or authorize application.
