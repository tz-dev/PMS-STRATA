## 3. Contract Lock

### 3.1 Governing question

> What additional structure is required to move from a configuration and event relation to a sequence, path, trajectory, and path-dependence claim?

### 3.2 Required claims

Chapter 3 must establish:

1. `configuration → transition → sequence → path → trajectory` is a burden-increasing analytical chain, not an automatic derivation;
2. a trajectory is a temporally ordered path with sedimented historical load that changes present meaning, costs, or continuation possibilities without implying teleology;
3. path dependence is a property claim about historical determination, not a separate object class;
4. `Θ` alone does not establish trajectory formation, sedimentation, irreversibility, or path dependence;
5. non-events require supported expectation relations and bounded realization conditions;
6. irreversibility remains frame-bound and claim-bound;
7. unrealized alternatives require historical or structural availability evidence.

### 3.3 Required distinctions

| Distinction | Required Chapter 3 burden |
| --- | --- |
| state vs. configuration | distinguish formal shorthand from richer praxeological reconstruction |
| event vs. non-event | distinguish realized relevant change from supported structured non-realization |
| event vs. transition | distinguish a change object from the relation connecting configurations |
| transition vs. state difference | require order, intervening structure, changed praxis conditions, and bounded relation |
| chronology vs. sequence | distinguish mere dating/enumeration from a declared ordered analytical series |
| sequence vs. path | require actually traversed relevant configurations/transitions and a selection relation |
| path vs. trajectory | require sedimented historical load and changed continuation conditions |
| trajectory vs. path dependence | treat path dependence as an additional property claim |
| duration vs. sedimentation | require accumulated structural load, not elapsed time alone |
| directionality vs. teleology | allow constrained direction without goal, destiny, progress, or decline claims |
| bounded irreversibility vs. absolute irreversibility | declare frame, claim, relation, and relevant restoration test |
| unrealized alternative vs. fiction | require source-supported historical availability or blockage |

### 3.4 Prohibited claims

Chapter 3 must not claim that:

- chronological order is sufficient for a path;
- any path is automatically a trajectory;
- any trajectory is strongly path-dependent;
- `Θ` alone creates sedimentation or path dependence;
- long duration increases truth, depth, or authority;
- an event must be punctual, simple, or causally isolated;
- a non-event is absent data, silence, or any imaginable unrealized possibility;
- endpoint difference establishes a transition;
- a trajectory has a necessary goal or direction of progress/decline;
- an unrealized alternative was available without source support;
- irreversibility is metaphysical, absolute, or context-free;
- a Chapter 3 temporal object is already an admissible `COMPOSE` result;
- a temporal label supplies operation identity, causal proof, or application authority.

### 4.2 Configuration and state decision

`state` is retained only as a formal or compressed shorthand for a temporally located description. `configuration` is the preferred Chapter 3 category where operator relations, non-events, action corridors, asymmetries, bindings, or internal dynamics are relevant.

```text
state shorthand
≠ complete praxeological configuration

configuration
≠ static ontology
≠ total description of a time slice
```

Chapter 3 may compare the adequacy of a state description with a configuration reconstruction. It may not claim that every formal state is invalid or that configuration captures the whole world.

### 4.3 Event decision

Chapter 1's `event-like object` remains the eligibility category. Chapter 3's `event` adds temporal placement, relevance to the declared chain, and relation to configurations and transitions.

```text
event-like object
→ eligible realized-change object

event
→ temporally specified realized relevant change within a declared chain
```

An event may be punctual or extended, simple or composite, and causally entangled. It does not automatically establish a transition or path.

### 4.4 Non-event decision

Chapter 3 inherits the Chapter 1 expectation gate and strengthens temporal placement:

```text
supported expectation
+ bounded realization condition
+ source-supported non-realization
+ praxeological load
+ temporal-chain relevance
→ non-event candidate
```

The chapter must keep separate:

```text
missing record
unknown occurrence
ordinary absence
conceivable alternative
structured non-event
```

A non-event may contain positive sub-events and may become central to a path or trajectory. This does not make every delay or silence path-forming.

### 4.5 Transition decision

Chapter 3 inherits the Chapter 1 minimum transition-object burden and adds explicit temporal-chain placement. A transition is not an empty arrow between endpoints and not a synonym for event.

Required relation burden:

```text
identifiable configurations
+ supported temporal order
+ intervening realized and/or non-realized structure
+ changed praxis conditions
+ bounded transition relation
→ transition candidate
```

Causal completeness is not required, but source-supported relational load is.

### 4.6 Sequence decision

A sequence is more than an unordered set and may be more than a raw chronology, but it remains weaker than a path. It requires an explicit ordering basis and selected analytical units. It does not require a strong constitutive historical relation among all units.

```text
dated enumeration
≠ warranted sequence automatically

sequence
≠ path
```

The chapter must state whether the sequence is source order, event order, transition order, record order, or analyst-imposed presentation order.

### 4.7 Path decision

A path is the selectively reconstructed, actually traversed chain of relevant configurations and transitions under a declared frame, scope, and granularity. It may include events, non-events, branch points, rejected continuations, and supported unavailable alternatives.

A path claim requires at least:

- a bounded reference object;
- ordered configurations and transitions;
- a selection rule;
- a relation showing why the selected chain is one path rather than a list;
- source trace for actual traversal;
- declared omitted branches and losses;
- no automatic trajectory or target-function claim.

The full `COMPOSE` procedure remains for Chapter 15.

### 4.8 Trajectory decision

A trajectory is not simply a longer path. It requires sedimented historical load that affects later meaning, cost, accessibility, role, asymmetry, binding, residue, or continuation possibility.

```text
path
+ source-supported sedimented historical load
+ changed later possibility structure
→ trajectory candidate
```

A trajectory may be directional without teleology. Several competing trajectory reconstructions may remain locally co-valid or underdetermined.

### 4.9 Path-dependence decision

Path dependence is a property of a bounded historical claim, not an object class and not a synonym for trajectory.

A minimum property test asks whether:

- the current configuration is insufficiently reconstructible from current conditions alone;
- prior order or branch selection changes present meaning, costs, or reachability;
- a supported alternative order would materially alter the present claim;
- the historical effect remains traceable rather than rhetorically invoked.

A trajectory may remain admissible while a stronger path-dependence claim is reduced or stopped.

### 4.10 Sedimentation decision

Sedimentation means accumulated historical load, not duration. It may be carried by supported combinations such as:

```text
Α + Θ  recurrent stabilization over time
Ω + Θ  accumulated asymmetric cost or exposure
Ψ + Θ  binding that persists or becomes costly
Λ + Θ  accumulated non-realization, residue, delay, or closure pressure
```

These pairings are prompts for reconstruction, not automatic formulas or sufficient conditions.

### 4.11 Irreversibility decision

Irreversibility is always declared relative to a frame, claim, object relation, and restoration criterion. The chapter must specify what cannot be restored, neutralized, or made cost-equivalent under the tested claim.

```text
exit
≠ return to untouched origin

recontextualization
≠ erasure of prior load

bounded irreversibility
≠ metaphysical impossibility of reversal
```

### 4.12 Unrealized-alternative decision

An unrealized alternative must have a supported availability relation. It may have been available, delayed, blocked, rejected, made costlier, or rendered unavailable by prior path structure.

```text
analyst-imaginable option
≠ historically available alternative
```

Chapter 3 defines the category and burden. Chapter 13 later supplies the fuller branch, abort, delay, and unavailable-alternative taxonomy.

## 5. Burden-Increasing Temporal Object Chain

The future chapter must present the chain as increasing burden, not automatic derivation:

| Stage | Minimum retained burden | What is not yet established |
| --- | --- | --- |
| configuration | bounded temporally located relevant relations | transition, sequence, path |
| transition | two or more configurations plus supported connecting relation and changed praxis conditions | sequence or path |
| sequence | selected ordered analytical units and ordering basis | actual traversed constitutive path |
| path | actual traversed relevant chain, selection rule, relation, source trace, loss | sedimented trajectory |
| trajectory | path plus source-supported sedimented load affecting later meaning/cost/possibility | strong path dependence |
| path dependence | separate property test showing present structure depends materially on prior order/path | causal law, determinism, prediction |

The chapter must make claim reduction downward possible:

```text
path-dependence claim fails
→ trajectory may remain

trajectory burden fails
→ path may remain

path burden fails
→ sequence may remain

sequence burden fails
→ bounded chronology or source ordering may remain
```

Failure at a stronger stage does not erase a warranted weaker stage. A new label cannot rescue a failed stronger claim.

### 8.7 PATH Chapters 9–12 boundary

Chapter 3 defines sequence, path, trajectory, path dependence, sedimentation, irreversibility, and alternatives. PATH operationalizes formation, testing, composition, and local result handling without redefining them.

### 8.8 Chapter 13 boundary

Chapter 3 defines unrealized alternatives minimally. Chapter 13 owns the full branches, aborts, delays, and unavailable-alternatives taxonomy.

### 8.9 Chapter 15 boundary

### 8.11 LIMITS boundary
