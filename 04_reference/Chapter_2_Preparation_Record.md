## 3. Contract Lock

### 3.1 Governing question

> How can a reconstruction declare context, resolution, relative position, time, sources, and claim reach without collapsing these dimensions into one vague language of levels?

### 3.2 Required claims

Chapter 2 must establish three linked claims.

1. **Coordinate independence:** frame, granularity, and relative level are independent but related analytical coordinates.
2. **Plurality without privilege:** multiple granularities may be valid for the same reference object or claim family; no granularity possesses automatic truth, depth, or authority priority.
3. **Relational level:** micro, meso, and macro are optional local abbreviations only where the comparison relation is explicit.

The chapter must also define temporal scope, source scope, claim scope, and a minimal coordinate declaration sufficient for later operation families.

### 3.3 Required distinctions

The future draft must make non-confusable:

- Frame operator type versus declared analytical frame;
- frame versus granularity;
- frame versus transformation context;
- granularity versus relative level;
- granularity versus resolution-test result;
- relative level versus ontological layer;
- source relative level versus target relative level;
- temporal scope versus temporal ordering, path, or trajectory;
- source scope versus source basis and source ceiling;
- source scope versus claim scope;
- claim scope versus claim boundary and claim ceiling;
- changed frame versus changed granularity;
- changed granularity versus changed relative level;
- granularity mismatch versus substantive contradiction;
- coordinate change versus operation identity.

### 3.4 Prohibited claims

Chapter 2 must not claim that:

- frames, granularities, or levels are universal natural units;
- the `□` operator type is identical with every analytical frame declaration;
- finer detail is automatically deeper, truer, more causal, or more authoritative;
- higher relative position is more comprehensive, valid, or important;
- a frame change is automatically vertical movement or `PROJECT_AS`;
- a granularity change automatically changes the source object or target function;
- micro, meso, and macro are fixed cross-domain bins;
- granularity mismatch automatically dissolves a real disagreement;
- the minimal coordinate declaration is a complete Shared Transformation Record;
- machine-readable coordinate completeness establishes substantive adequacy.

### 4.1 Frame terminology decision

The draft must use three separate grammatical objects:

```text
`□`
→ operator sign

`Frame`
→ PMS operator name and operator type reference

analytical frame
→ declared reconstruction coordinate, instantiated in a bounded analysis
```

A concrete analytical frame may be reconstructed through one or more Frame occurrences, but it is not the abstract operator type itself. Conversely, naming the `□` type does not yet supply a complete analytical frame declaration.

### 4.2 Granularity terminology decision

`Granularity` names the selected resolution and distinction density of a reconstruction. It does not name the outcome of testing a finer reconstruction.

```text
granularity
≠
resolution gain
≠
resolution neutrality
≠
resolution drift
≠
resolution escape
```

Those outcomes remain owned by Chapter 25.

### 4.3 Relative-level decision

A relative level exists only under an explicit relation containing at least:

- a reference object or reference pair;
- a comparison, part–whole, compositional, or functional relation;
- the local direction or position being asserted;
- the frame and claim for which the assertion matters.

The same object may be `micro` relative to one declared object and `macro` relative to another. No contradiction follows unless the same relation and claim are being asserted incompatibly.

### 4.4 Scope-family decision

The scope terms are separated as follows:

```text
temporal scope
→ which time span and open temporal edges are included

source scope
→ which source-supported materials and distinctions are accessible

claim scope
→ where and how far the claim applies
```

Related but separately owned terms remain:

```text
source basis
→ actual supporting materials

source ceiling
→ maximum support those materials can bear

claim boundary
→ overall permissible edge of the claim and its authority

claim ceiling
→ maximum asserted strength or reach currently warranted

validity scope
→ Chapter 5 contextual validity of a target function
```
