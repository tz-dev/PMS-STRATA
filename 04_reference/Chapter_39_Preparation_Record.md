## 6. Boundary and Counterfactual Architecture

Chapter 39 must remain vulnerable to at least the following pressures:

1. **Label-removal pressure:** does the claimed gain remain when the PMS-derived label is removed?
2. **Source-only pressure:** can the target scene be reconstructed equally well by retaining the source as background relevance without a new function?
3. **Target-difference pressure:** what concrete action corridor, expectation, cost, interpretation, coordination, or continuation difference changes?
4. **Constitutive-source pressure:** which source features carry the function, and which are merely cited?
5. **Source-variation pressure:** which material source change would alter or defeat the function?
6. **Irrelevant-source pressure:** which source changes should leave the bounded function unchanged?
7. **Opposite-source pressure:** do contrary source structures support the same function without revision?
8. **Target-condition pressure:** do present target conditions carry the entire explanatory load?
9. **Alternative-function pressure:** does another bounded target function discriminate better with fewer assumptions?
10. **Analogy pressure:** is formal or structural resemblance all that survives?
11. **No-projection pressure:** is source-only description the more accurate result?
12. **Elasticity pressure:** is the function renamed, multiplied, narrowed, or recontextualized after every objection?
13. **Loss pressure:** are preserved, compressed, excluded, uncertain, and irrecoverable structures explicit?
14. **Stop pressure:** would continuation require source erasure, type replacement, arbitrary context, or anti-immunization violation?
15. **Non-Capture pressure:** can the competing functions or semantic relation be responsibly distinguished without invention?

Counterfactual sensitivity remains a qualitative test discipline, not causal proof, probability, prediction, or authority.
