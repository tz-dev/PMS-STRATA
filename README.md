# PMS-STRATA

## Purpose

**PMS-STRATA** is a corpus-form transformation and granularity-discipline repository within the PMS ecosystem.

It specifies how praxis structures may be composed, decomposed, and functionally projected across declared granularities and relative levels while preserving source traceability, origin-type integrity, transformation loss, claim boundaries, stop conditions, and non-capture.

Its compact rule is:

```text
more structure ≠ more authority
```

PMS-STRATA does not turn analytical recursion into ontology, proof, superiority, or immunity from failure.

## Operational Vocabulary

STRATA uses three canonical transformation operations:

| Operation | Short function | Boundary |
| --- | --- | --- |
| `COMPOSE` | Forms a composite analytical object from multiple or sequential source structures. | Composition does not create totality or higher authority. |
| `DECOMPOSE` | Reconstructs a compressed occurrence or composite under finer granularity while preserving the same reference object. | Finer resolution is not higher truth or final constituent access. |
| `PROJECT_AS` | Projects an origin-typed source object as a bounded contextual target function. | Projection is not replacement, semantic identity, or origin-type erasure. |

Operation Vocabulary Closure:

```text
Every admitted STRATA transformation must be typed as COMPOSE, DECOMPOSE,
PROJECT_AS, or a finite declared chain of their separate occurrences.
```

A candidate that cannot be typed this way requires corpus-level revision. It may not be introduced locally as an informal fourth operation.

## Admissibility Band

STRATA controls level movement through an admissibility band:

```text
Praxeological Traceability Ceiling
─────────────────────────────
admissible transformation
─────────────────────────────
Praxeological Relevance Floor
```

Lower boundary:

```text
A distinction below praxeological relevance is not a discovery.
It is resolution without purchase.
```

Upper boundary:

```text
A composition above praxeological recognizability is not a higher-level structure.
It is a label without traceable load.
```

A source citation is not by itself a constitutive source trace. A formally elegant transformation can still fail if the source load, loss, type integrity, or claim ceiling is not preserved.

## Transformation Record and Loss

STRATA uses a shared transformation record architecture for operation occurrences and declared chains.

A valid record keeps at least these burdens visible:

| Burden | Function |
| --- | --- |
| source trace | What material carries the transformation. |
| operation kind | Whether the move is COMPOSE, DECOMPOSE, PROJECT_AS, or a declared chain. |
| origin type | What the source object is before projection or retyping. |
| target context | Where the projected or composed function is being claimed. |
| transformation loss | What is selected, compressed, omitted, displaced, or made non-transferable. |
| alternatives | What plausible transformation was not selected. |
| stop / non-capture | Where a transformation must fail, stop, or remain unresolved. |
| claim ceiling | What the record may and may not support. |

Loss is not a scalar and is not automatically additive. For operation chains, local Loss profiles remain separately preserved.

## Output Classes

STRATA uses ten canonical Output Classes:

| Output Class | Use |
| --- | --- |
| `admissible` | Transformation passes with its declared claim ceiling. |
| `admissible_with_bounded_claim` | Transformation is usable only under a narrowed claim. |
| `admissible_but_provisional` | Transformation is usable but source, calibration, or comparison limits remain active. |
| `resolution_neutral` | Finer distinction does not change praxeological load. |
| `analogy_only` | Similarity can be discussed but cannot bear projection. |
| `partially_admissible` | Some part of the transformation holds; another part must be excluded or reduced. |
| `claim_reduction_required` | The operation may remain only after lowering its claim. |
| `mandatory_stop` | The transformation must not proceed under current source, use, or protection conditions. |
| `failed_transformation` | The declared operation fails. |
| `non_capture` | The packet remains unresolved without forced classification. |

Optional Stop is not an eleventh output class. Stop is a controlled endpoint or non-continuation condition.

## What STRATA Is Not

PMS-STRATA is not:

```text
PMS Base
Meta-PMS
ontology of levels
proof system
source of application authority
reader authority
schema authority
anti-objection machinery
immunity layer
```

Compact reductions:

```text
finer resolution ≠ higher truth
higher composition ≠ greater authority
projection ≠ replacement
operation closure ≠ completeness proof
schema validity ≠ substantive validity
reader graph ≠ ontology
more structure ≠ more authority
```
