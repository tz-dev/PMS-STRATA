## 1. Governing Chain Question

Can four independently bounded local asymmetry occurrences first be composed into one relational composite and then projected as a bounded higher-level access function, while reference, origin type, relation topology, temporal load, operation-specific Loss, failure, and authority ceilings remain distinct?

```text
COMPOSE success
≠ automatic target function

PROJECT_AS success
≠ source-type replacement
≠ stronger authority

later nominal failure
≠ invalidation of earlier success
```

## 2. Source Fixture

| ID | Local occurrence | Time | Source-bounded load |
|---|---|---|---|
| `A1` | review-initiation access asymmetry | `T0–T1` | only `r1` can initiate exception review |
| `A2` | delay-exposure asymmetry | `T1–T2` | `r2` bears backlog while review is pending |
| `A3` | exit-cost asymmetry | `T2–T3` | `r3` can leave only by absorbing duplicated work and release cost |
| `A4` | repair-capacity asymmetry | `T3–T4` | `r4` controls repair and reallocation |

The constitutive relation topology is:

```text
A1 → A2  restricted entry transfers delay
A2 → A3  accumulated delay increases exit cost
A4 → A3  centralized repair controls reduction of exit cost
A3 → A1  high exit cost reinforces later reliance on the same entry gate
```

Component co-presence alone is insufficient.

## 3. Occurrence A — COMPOSE

`C47-CP1A` forms derived relational composite `Q47` from `A1–A4` and their source-traceable relations.

The retained claim is deliberately narrow:

```text
A1–A4
+ constitutive relation topology
+ T0–T4 order
→ derived relational composite Q47
```

`COMPOSE` does **not** establish:

- a higher-level access function;
- operator identity;
- quantitative component weights;
- causal monopoly;
- person typing;
- application authority.

**Local route:** `admissible_with_bounded_claim`.

## 4. Continuity Handoff

The handoff from `C47-CP1A` to `C47-CP1B` preserves:

- the same `Q47` historical/structural referent;
- origin type `derived relational composite`;
- all four source occurrences and constitutive relations;
- `T0–T4` ordering and relation windows;
- source gaps and uncertainty;
- the complete C47-CP1A five-part Loss;
- the explicit no-function boundary of COMPOSE.

```text
handoff
≠ inherited target function
≠ inherited Output Class
≠ inherited authority
```

## 5. Occurrence B — PROJECT_AS

Within target field `H47`, `Q47` performs a bounded higher-level access function because the relation topology jointly changes:

- review entry;
- delay distribution;
- exit accessibility;
- repair access;
- the later action corridor.

Comparison field `I47` preserves similar local differences but removes coordination and target uptake. `I47` therefore receives no projection.

```text
Q47 origin type retained
+ H47 target context declared
+ source-sensitive target difference
→ bounded higher-level access function
```

**Local route:** `admissible_with_bounded_claim`.

## 7. Counterfactual and Alternative Pressure

The higher-level function weakens or disappears when:

- initiation access is equalized;
- repair access is decentralized;
- exit cost is lowered independently;
- the load-transfer relations are removed;
- the same local differences occur in `I47` without coordination and target uptake.

A smaller subset may carry most target load. That remains an unresolved new-source/new-projection claim rather than being silently repaired inside the present chain.

## 8. Required Continuity Failure — C47-CP1C

A later source reuses the name `Q47*`, but substitutes `A2` and `A4`, dissolves the load-bearing relations, and leaves target field `H47*` unchanged when the nominal source is removed.

```text
same name
+ changed referent
+ absent load-bearing relations
+ source-insensitive target
→ failed_transformation
```

The failure does not invalidate `C47-CP1A` or `C47-CP1B`. It establishes only that nominal sameness cannot carry Reference or Functional Continuity.

## 9. Operation-Specific Loss

- excludes automatic macrofunction and authority;
- marks contribution weights uncertain;

### C47-CP1C

- excludes the attempted same-function projection;
- keeps changed-ground re-entry possible without preauthorization.
