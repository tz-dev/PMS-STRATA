## 1. Case Statement

The bounded service-activation Path from `C17-LINEAR-01` is entered into a synthetic renewal-review registry at `t4`. The registry assigns the label **eligibility-gate function** to every Path containing an authorization token. The analyst then claims that the source Path performs that target function in scene `R1`.

The registry label is technically well formed, context-named, and reproducible. It nevertheless ignores the source Path's constitutive order, continuation relations, selection, and Loss. Altering those features while retaining the authorization token leaves the label unchanged.

```text
successful label assignment
≠ contextual target function

technical translation success
≠ PROJECT_AS passage
```

This is a synthetic method-and-record test. It is not external empirical evidence, a real eligibility determination, causal proof, or application authority.

## 11. Canonical Routing

The selected Output Class is:

```text
failed_transformation
```

Why not `analogy_only`?

The delimited claim asserts a contextual function, but no affirmative resemblance with useful correspondences and breaking points is retained. A label alone is not an analogy.

Why not `claim_reduction_required`?

Reducing the claim to “the registry assigns this string” changes the tested function claim into a separate metadata statement. It does not preserve a narrower function.

Why not `mandatory_stop`?

The attempted operation has already been executed and evaluated. The correct route is failure of the declared transformation, not a pre-operation prohibition.

Why not `non_capture`?

Only one source-indifferent projection has failed. Other projections, analogy, or no projection remain available.
