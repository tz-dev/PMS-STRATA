# Case Markdown Record Companions

This directory contains exactly one same-basename Markdown companion for each Shared Transformation Record in `../yaml/`.

```text
record companions: 59
YAML records:      59
pairing:           complete
```

Shared multi-record case and chain narratives are stored separately in [`../packages/`](../packages/). A companion does not duplicate the package's full narrative and does not create another operation occurrence.
