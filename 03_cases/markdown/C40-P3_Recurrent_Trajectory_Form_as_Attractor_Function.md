## 1. Case Statement

Three independently warranted synthetic Trajectories support one bounded recurrent transition form:

```text
temporary exception or provisional arrangement
→ coordination deferral or incomplete reset
→ resource and role lock-in
→ constrained reopening or partial repair
```

Within later transition field `C3`, that origin-typed recurrent-form composite performs a bounded **dynamic attractor-function** because the recurrent course form changes the accessibility, friction, expectation, role allocation, and reopening cost of later continuations.

The claim is not that the source becomes `Α`, that later paths must repeat, or that recurrence proves a causal or probabilistic law.

```text
recurrent trajectory form
≠ PMS Attractor operator type
≠ Attractor-typed occurrence
≠ deterministic recurrence
≠ person or group type
```

This is a synthetic method-and-record test. It supplies no external empirical calibration, causal proof, prediction, norm, recommendation, or application authority.

### Recurrent-form source claim `R3`

The recurrent source object is a derived recurrent-form composite, not an average and not a universal label. Its constitutive relation is:

```text
provisional exception
+ deferred or incomplete coordination reset
+ resource/role lock-in
+ reopening that is narrower or more costly than a clean reset
→ recurrent transition form R3
```

Trajectory-specific surface differences remain visible. `T1` contains a warrantable central Non-Event; `T2` contains two historically connected cycles; `T3` contains a completed review but defers full redistribution into a repeated rotation. These differences are allowable only because the recurrent relation concerns **incomplete reset and retained load**, not one identical visible event.

### Target context `C3`

`C3` is one later synthetic cross-unit transition field in which a new temporary service exception arises after `R3` has become an explicit planning precedent:

- the familiar provisional route has an available approval template;
- roles and reserved resources are already organized around continuation rather than clean reset;
- full redesign requires releasing existing commitments and an additional cross-unit decision;
- partial reopening is easier than full reopening;
- alternative sequences remain possible but carry higher friction in the declared window.

Comparison field `E3` holds the visible sequence approximately constant while removing source-form uptake: current lock-in alone generates the sequence, approvals are symmetric, and the prior recurrent form changes no access or cost. `E3` therefore receives **no projection**.

### Claim Ceiling

The case may assert only that `R3`, while retaining origin type `derived recurrent-form composite`, performs one bounded dynamic attractor-function in `C3` with respect to transition access, expectation, role recurrence, resource commitment, and reopening friction.

Excluded are:

### Break conditions

The source-form claim weakens, fails, or requires revision if:

- one source Trajectory is selected only because it fits the desired target result;
- the incomplete-reset relation is removed from two source Trajectories;
- resource/role lock-in is replaced by a clean reset without residual continuation cost;
- opposite sequences are admitted under the same elastic label;
- `T1`, `T2`, or `T3` boundaries are materially changed without a new source claim;
- relevant divergent or truncated Trajectories are suppressed.

`C17-WEAKPD-01` remains explicit counterpressure: repeated visible cycles with current-state sufficiency may support recurrence description while failing to establish the same historical attractor load.

## 5. Attractor Load

The target function is dynamic because it stabilizes a **transition form**, not a final state.

| Target dimension | `C3` difference supported by the fixture |
|---|---|
| friction | the familiar provisional route uses an existing approval path while clean reset requires additional release and coordination |
| expectation | actors enter the scene expecting provisional continuation and partial reopening rather than full redesign |
| role recurrence | coordination and burden-carrier roles are preallocated by the planning precedent |
| resource commitment | reserved resources and residual commitments favour continuation of the known course form |
| reopening corridor | partial reopening remains accessible; clean reopening is narrower and more costly |
| alternative accessibility | alternatives remain possible and are not treated as impossible, but their access cost is higher in the bounded window |

```text
attractor-function
→ changes transition accessibility and persistence

attractor-function
≠ forces repetition
≠ proves probability
≠ explains every target feature
```

The function is source-sensitive. In `E3`, removing source-form uptake while holding visible sequence similarity approximately constant eliminates the additional transition-access difference. The correct result there is no projection.

## 6. Counterfactual Attractor Test

The claim is strongly but not absolutely sensitive:

1. **remove `T1`:** the source claim survives only as a narrower and more provisional two-Trajectory candidate;
2. **remove two source Trajectories:** no recurrent-form source remains;
3. **complete reset in `T1` and `T2`:** incomplete-reset recurrence and later reopening load are defeated;
4. **remove target planning-template uptake:** current conditions may remain, but `R3` no longer performs a distinct function;
5. **equalize approval and release costs:** the familiar route loses its friction advantage;
6. **same visible sequence in `E3`:** similarity alone does not support projection;
7. **different visible form with equivalent role/resource/reopening load:** the dynamic function may remain supportable despite surface variation;
8. **replace target conditions materially:** a new target claim and record are required.

These mutations test structural dependency. They do not prove causality.

## 9. Alternatives

### Rival projections

- **descriptive recurrence only:** retain `R3` as a bounded source description without target function;
- **narrower claim:** one role-relation or reopening-cost effect in `C3` only;
- **static function:** test configuration persistence separately rather than transition-form stabilization;
- **current-condition account:** explain `C3` through present lock-in without source-form function;
- **analogy only:** retain formal sequence resemblance without functional continuity;
- **no projection in `E3`:** visible similarity without source-dependent access or cost difference.

### Rival source accounts

- common maintenance or coordination frame;
- independently regenerated temporary solutions;
- survivorship or source-selection bias;
- multiple non-equivalent recurrent forms;
- no stable recurrent source object.

### Unresolved

A different source set or a narrower recurrent-form boundary may become preferable, but it requires a new source claim rather than target-driven revision of `R3`.
